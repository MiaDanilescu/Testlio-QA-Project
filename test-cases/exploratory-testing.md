# Exploratory Testing

## Charter

**Objective:**
Evaluate the Testlio website from the perspective of a first-time visitor.

**Areas to Explore:**
- Navigation
- Main CTAs
- Page content
- Links
- Responsive behavior
- Usability

**Test Approach:**
1. Start from the homepage.
2. Navigate through the main sections.
3. Follow important links and CTAs.
4. Try different screen sizes.
5. Look for unexpected behavior, broken links, layout issues, or confusing user experiences.

**Expected Outcome:**
Important customer journeys should work as expected and the website should provide a clear and usable experience.

## Findings

Findings will be documented only if an actual issue is discovered during testing.
