# Testlio-Inspired QA Automation Project

## Overview

This is an independent QA automation portfolio project inspired by the public Testlio website.

The goal is to demonstrate a practical approach to manual testing, exploratory testing, and UI automation using Playwright and TypeScript.

> This is an independent portfolio project and is not an official Testlio project.

## Testing Approach

- Functional testing
- Smoke testing
- Regression testing
- Exploratory testing
- Responsive testing
- Cross-browser testing
- Basic accessibility testing
- UI automation

## Automation

### Tools

- Playwright
- TypeScript
- GitHub Actions

### Design Pattern

Page Object Model (POM)

The Page Object Model separates page actions from test logic, making the automation easier to maintain.

## Browsers

Automated tests are executed against:

- Chromium
- Firefox
- WebKit
